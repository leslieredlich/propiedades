## 🔧 **Cómo Personalizar**

### **Opción 1: Desde WordPress Customizer**
1. **WordPress Admin** → **Apariencia** → **Personalizar**
2. Buscar **"Tipografía"**
3. Ajustar los valores según tus preferencias

### **Opción 2: Valores Recomendados para la Imagen**
```
Títulos Principales (H1): 2.25rem
Subtítulos (H2): 1.5rem
Títulos de Sección (H3): 1.25rem
Precios: 2rem
Características: 1.5rem
Texto Normal: 1rem
Texto Pequeño: 0.875rem
```
